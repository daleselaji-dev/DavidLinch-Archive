## 一、触发机制验证

### 1.1 几何精度 ⭐⭐⭐⭐⭐ (5/5)

**测试结果**：触发在"快要看见墙后"的几何瞬间，滞后 **1.4cm/零帧**

**证据**（r6 probe B跑）：
- 显形线理论跨点：z = -26.506m（巷轴 x=9.3）
- 细步实录最后两帧：
  - z=-26.46, cross=+0.039（差 3.9cm 未跨）
  - z=-26.52, cross=-0.012（过线 1.4cm）**同帧引爆**
- 真机 60fps × 4.2m/s 单帧步长 = 7cm
- **结论**：触发粒度 = 一帧脚步，不提前不拖延

**机械账目零矛盾**：
```
显形线 = K(8.05,-26.8) - R(7.2,-27.0) 连线
中巷线 x=9.3 跨线点：z ≈ -26.506
冒烟停点：z = -24.6（跨线前）
工装进区步：z = -26.79（跨线后 0.28m）
```

### 1.2 朝向判定 ⭐⭐⭐⭐⭐ (5/5)

- ✅ 面南行走（yaw 0）→ 跨线即触发
- ✅ 背向北归（yaw π）→ 穿区不触发
- ✅ 线南驻留面朝东墙 → 不触发，转回西南瞬间 → 触发
- ✅ 视锥判定：±fov/2（约 ±60°），不需完全对正目标

## 二、单拍节奏评价

基于 SCARE_BEATS 实时钟与 r6 probe 逐帧实录：

### 2.1 接近压迫（跨线前） ⭐⭐⭐⭐ (4/5)
- **APPROACH_DREAD 涨落区**：z ∈ [-21.5, -26.4]，约 5m 推进
- **心跳渐密**：2.1s → 0.65s（游戏钟累加，软渲染安全）
- **巷灯渐次不稳**：lampDread 通道 0.42 系数进两盏巷灯
- **冷却静音门**：触发后 cornerTrig.armed() = false，恐惧静音至冷却走完
- **评价**：渐进式张力构建，但未达"极度压迫"（原片 BOB 拐角前的窒息感）
  - 改进建议：可考虑增加视觉扭曲（edge distortion）或降低 FOV 模拟压迫

### 2.2 跨线瞬间（reveal 0ms） ⭐⭐⭐⭐⭐ (5/5)
- **灯一口气全灭**：lampPanic.v=0, lampDread.v=0, lampKill.v=1（一步到位，无狂闪前奏）
- **剪影光起**：rim 初值 4.83（打火过冲，前 90ms）
- **刮擦声定位**：sfxAt('scrape', CORNER_EDGE.x, CORNER_EDGE.z) - 钉在拐角沿
- **低频升压**：sfx('dreadswell', 0.75, punch=true) - 直通惊吓总线
- **音频塌陷**：audio.duck() 压缩其他声源
- **评价**：**瞬间黑暗转换完美**，与原片 BOB 拐角"世界一秒变色"节奏一致

### 2.3 滑出（reveal 0-550ms） ⭐⭐⭐⭐ (4/5)
- **路径**：revealBez 二次贝塞尔，藏身点 R(7.2,-27.0) → 拐角沿 K(8.05,-26.8) → 现身点 out(7.73,-27.0)
- **时长**：550ms（比 v1.12 的 2.4s 顿挪前奏砍掉 77%）
- **体态曲线**：lurchEase(s) 顿挪三步，每步后段"死死停住"（平台段）
- **距离**：现身点离中巷线跨线玩家 ~0.9m（贴脸但不重叠）
- r6 实录：
  - F15: aim 61.9° → 19.7°（镜头急速转向）
  - F16: aim 19.7° → 0.8°
  - F17: aim 0.8° → **0.0°**（锁定完成）
- **评价**：**闪出速度够快**，但顿挪动画可能削弱"滑出"的流畅惊悚感
  - 改进建议：可考虑 reveal 阶段用纯 smoothstep（保留 lurch 给 stare/rush）

### 2.4 错拍/盯视（stare 550-1500ms，持续 950ms） ⭐⭐⭐⭐⭐ (5/5)
- **站住不动**：wraith.position 冻结在 out 点，lookAt 持续对准玩家
- **镜头锁定**：aim 0.0°，yaw/pitch 每帧 lookAt 跟焦
- **剪影光呼吸**：rim 2.5~6.9 按 sin 波动（与眼焰错半拍）
- **歪头**：STARE_TILT 在错拍中段（at=0.32, span=0.38）缓缓歪 0.075 rad - "不对劲"语言
- **FOV 慢推开始**：69.8° → 68.4°（smoothstep 起步几乎不动）
- **评价**：**原片 BOB 核心节奏完美还原** - "它先看你"的恐怖静止
  - 错拍持续 950ms 足够让观众从震惊转入绝望
  - 歪头细节加强"核对你"的不人性感

### 2.5 扑近（rush 1500-1900ms，持续 400ms） ⭐⭐⭐⭐ (4/5)
- **加速**：dist 1.09m → 0.95m（r6 实录，软渲染游戏钟 0.28 倍速受限）
  - 真机预期：0.4s 冲到 0.85m（账目设计）
- **眼窝烧起**：eyeMat.emissiveIntensity 1.2 + k*...
- **发帘后甩**：hair.rotation.x = -0.14*k 叠加高频扑动 sin(t*13)
- **剪影涌光**：rim 6.9 → 8.2（surge 3.4 系数）
- **雾涌**：engine.fogSurge() 世界收紧（乘法瞬态 + 指数衰减）
- **FOV 推速最快**：68.4° → 63.1°（push ≈ 0.35）
- **评价**：**动作设计到位**，但软渲染无法验证真机 0.4s 全速扑击效果
  - 改进建议：可能需要真机用户反馈确认"够不够吓人"

### 2.6 闷击（shock 1900ms） ⭐⭐⭐⭐⭐ (5/5)
- **后处理冲击**：engine.shock(1, 0.9, 0x1a0000) - 暗红闪帧
- **uShock 值**：0.82 起，指数衰减（r6 F21: shock=0.82）
- **心跳音效**：sfx('heartbeat') 在 rush 中段已响
- **评价**：**视觉冲击强烈**，暗红色调与林奇美学一致

### 2.7 醒来（wake 3300ms + WAKE_DAZE） ⭐⭐⭐⭐ (4/5)
- **黑幕时长**：2400-3300ms = 900ms
- **空间错位**：(9.3,-26.52) → WAKE_POINT(9.7, 9.5) - 瞬移回巷口
- **醒来姿态**：yaw=0（面南朝巷），pitch=-0.36（俯冲醒）
- **shock 余波**：0.82 → 0.45 → 0.2（持续数秒）
- **镜头归还**：FOV 归还 70°，releaseGrab() 双保险
- **评价**：空间错位有效制造"失时感"，但醒来后缺乏环境变化（如灯光恢复）
  - 改进建议：可考虑醒来后巷灯缓慢重燃，增强"劫后余生"感

## 六、发现的问题

### 6.1 阻塞性问题
**无** - 机械层零病灶

### 6.2 体验优化建议

1. **接近压迫不足** (优先级：中)
   - 现状：心跳渐密 + 灯光不稳，但缺乏视觉压迫
   - 建议：
     - 跨线前 2m 开始降低 FOV（68° → 65°）模拟窒息
     - 增加边缘扭曲后处理（vignette 强化）
     - 考虑微幅减速玩家移动（speed × 0.95）

2. **滑出顿挪削弱流畅性** (优先级：低)
   - 现状：lurchEase 三步平台段"死死停住"
   - 建议：reveal 阶段单独用 smoothstep，仅 stare/rush 用 lurch

3. **醒来后缺乏环境变化** (优先级：低)
   - 现状：瞬移回巷口，但灯光/氛围无变化
   - 建议：
     - 巷灯缓慢重燃（lampKill.v 1→0，3s 淡入）
     - 增加一声远处门关闭/锁扣声（暗示"封印"）

4. **软渲染验证受限** (优先级：高)
   - 现状：WebGL2 blocklisted，无法手动视觉测试
   - 建议：
     - 提供 Docker 镜像（预装 GPU 驱动）
     - 制作官方演示视频（关键拍位慢动作）
     - 召集 5-10 名真机测试用户，收集"吓不吓人"主观评分
