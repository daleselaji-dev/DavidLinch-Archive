全部体验特性：
- **旁白四档模式**（`V` 循环）：**字母显现**（默认——旁白逐字打出，打字机音/故障字形/突兀静默拍）、
  **爵士+字母**（程序化「深夜爵士」氛围层：摇摆刷镲/行走贝斯/柔和和声/弱音铜管，全 WebAudio 合成，零录音采样）、
  **语音+字母**（戏剧化 TTS：分句停顿/变速/耳语拍）、关
- 每厅隐藏彩蛋（绕后触发的区域机关，含穆赫兰道「剧场背后」惊吓）
- 博物馆化展陈：玻璃展柜 + 林奇原话引语展签（访谈/著作短引语，中英对照+出处）
- 程序化 WebAudio 环境底噪（每厅不同配方）+ 27 种合成交互音效
- Bloom / 胶片颗粒 / 扫描线 / 色差 / 惊吓冲击 后处理链
- 留言墙（发帖/点赞/回复，localStorage 持久化）+ 房间内 3D 软木留言板
- 桌面 + 触屏双操作方案

## 快速开始

```bash
npm install
npm run dev        # 浏览器开发预览 (http://localhost:5173)
npm test           # 单元测试 (vitest)
npm run smoke      # 构建冒烟测试
npm run dist:win   # 打包 Windows x64 exe → release/
```

桌面运行（Electron）：`npm run build && npm start`

## 操作

- **WASD / 方向键** 行走（Shift 加速），**鼠标** 环视（点击画面锁定指针）
- **E / 点击** 与发光热点互动；**Esc** 关闭面板
- **L** 大厅 · **T** 年表 · **G** 留言墙 · **C** 合规页 · **M** 静音 · **V** 旁白模式（字母→爵士→语音→关） · **Q** 画质 · **F** FPS
- 触屏：左下虚拟摇杆移动，右半屏拖动环视，「互动」按钮触发热点

## 技术

Electron + Vite + Three.js。零素材资产：所有纹理由 Canvas 程序绘制，所有几何由代码构建，
所有声音（含爵士氛围层）由 WebAudio 振荡器/噪声实时合成，应用图标亦由 Node 脚本逐像素生成（`scripts/gen-icon.js`）。
各展厅模块动态 `import()` 分包懒加载（7 chunk）。

文案原则（v1.1）：少贴二手标签，尽量让林奇自己解释自己——展签采用其公开访谈与著作中的
**短引语**（注明出处类型，非商业粉丝纪念语境下的合理使用）；涉及潜意识与欲望结构时点到为止地
借用弗洛伊德/拉康/齐泽克的正统概念，不写论文墙。

「PS5 级别」在本项目中定义为**高完成度风格化实时渲染目标**（PBR 材质、全屏后处理链、体积氛围、
30fps+ 流畅第一人称探索），不虚假承诺主机独占画质——林奇的世界从不依赖清晰度，而依赖质地与光。
