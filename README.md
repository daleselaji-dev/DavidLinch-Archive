| 展厅 | 主题 |
|------|------|
| **THE VELVET FOYER** 天鹅绒大厅 | 总览大厅：黑白折线地板 + 红帷幕环廊 + 五扇门 |
| **THE ARCHIVE** 档案长廊 | 13 项条目的年表灯牌长廊 + 尽头纪念墙 |

| **BLUE VELVET** 蓝色房间 (1986) | 夜总会：蓝天鹅绒舞台 / 孤独话筒 / 可熄灭的桌灯 |
| **TWIN PEAKS** 黑松林 (1990) | 夜之松林：地表雾 / 萤火 / 林中独立的红帷幕之门 |

全部体验特性：程序化 WebAudio 环境底噪（每厅不同配方）+ 合成交互音效、
可开关的原创旁白（Web Speech API + 字幕降级）、Bloom/胶片颗粒/扫描线/色差后处理、
留言墙（发帖/点赞/回复，localStorage 持久化）、桌面 + 触屏双操作方案。

## 快速开始

```bash
npm install
npm run dev        # 浏览器开发预览 (http://localhost:5173)
npm test           # 单元测试 (vitest)
npm run smoke      # 构建冒烟测试
npm run dist:win   # 打包 Windows x64 exe → release/
```

桌面运行（Electron）：`npm run build && npm start`

## 操作

- **WASD / 方向键** 行走（Shift 加速），**鼠标** 环视（点击画面锁定指针）
- **E / 点击** 与发光热点互动；**Esc** 关闭面板
- **L** 大厅 · **T** 年表 · **G** 留言墙 · **C** 合规页 · **M** 静音 · **V** 旁白 · **Q** 画质 · **F** FPS
- 触屏：左下虚拟摇杆移动，右半屏拖动环视，「互动」按钮触发热点

## 技术

Electron + Vite + Three.js。零素材资产：所有纹理由 Canvas 程序绘制，所有几何由代码构建，
所有声音由 WebAudio 振荡器/噪声实时合成，应用图标亦由 Node 脚本逐像素生成（`scripts/gen-icon.js`）。
各展厅模块动态 `import()` 分包懒加载。

「PS5 级别」在本项目中定义为**高完成度风格化实时渲染目标**（PBR 材质、全屏后处理链、体积氛围、
30fps+ 流畅第一人称探索），不虚假承诺主机独占画质——林奇的世界从不依赖清晰度，而依赖质地与光。
