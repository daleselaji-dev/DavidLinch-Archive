## 快速开始

```bash
npm install
npm run dev        # 浏览器开发预览 (http://localhost:5173)
npm test           # 单元测试 (vitest)
npm run smoke      # 构建冒烟测试
npm run dist:win   # 打包 Windows x64 exe → release/
```

桌面运行（Electron）：`npm run build && npm start`

## 操作

- **WASD / 方向键** 行走（Shift 加速），**鼠标** 环视（点击画面锁定指针）
- **E / 点击** 与发光热点互动；**Esc** 关闭面板
- **L** 大厅 · **T** 年表 · **G** 留言墙 · **C** 合规页 · **H** 帮助 · **M** 静音 · **V** 旁白模式（字母→低语→爵士→关） · **Q** 画质 · **F** FPS
- 触屏：左下虚拟摇杆移动，右半屏拖动环视，「互动」按钮触发热点

## 技术

Electron + Vite + Three.js。零素材资产：所有纹理由 Canvas 程序绘制，所有几何由代码构建，
所有声音（含爵士氛围层）由 WebAudio 振荡器/噪声实时合成，应用图标亦由 Node 脚本逐像素生成（`scripts/gen-icon.js`）。
各展厅模块动态 `import()` 分包懒加载（7 chunk）。

文案原则（v1.5 —— show, don't tell）：不贴二手标签、不写策展文章、不借理论名词、
**不复述作品叙事情节**、**制作方法不入作品**（旁白/立牌/字幕不谈技术与工艺）。
旁白只剩 8 句 ≤16 字的风格化空间提示（合计 84 字），
每厅至多一座林奇原话引语立牌（访谈/著作短引语，注明出处类型，非商业粉丝纪念语境下的合理使用），
随行解释与评述各一句 ≤36 字，字幕短句 ≤22 字。其余交给空间、光、声与静默。
以上均为单测强制约束（`tests/narration.test.js` 源码级审计 + 叙事/元叙述禁词扫描）。

「PS5 级可游玩风格化实时画质」在本项目中落地为 `QUALITY_GATES.md` 门禁 26 的 **P1–P10
可勾选清单**（五通道 PBR 程序纹理组——albedo/normal/roughness/metalness/AO、大理石/层压板/
锈蚀新纹理族、三段 CDL 电影分级 + halation 暖晕、双层体积光锥、逐顶点呼吸幕布、
预算断言 240/240k/40 + 低画质档回退），不虚假承诺主机独占画质——
林奇的世界从不依赖清晰度，而依赖质地与光。
